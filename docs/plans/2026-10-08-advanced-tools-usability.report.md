## 4. 做了什么

### 4.1 可交互流程

- 我的任务：名称、可解释状态、下一步、搜索；不堆空统计卡
- 新任务：自然语言需求创建独立样例草稿；无需内部 ID，不自动创建真实 Run
- 对话：可输入、保存、看明确标注的固定样例回复；保留失败输入
- 进度：显示本任务的实际样例记录；无记录就“尚未开始”，需补充时给回到对话入口
- 文件与结果：同一任务的文本预览、真实 HTTP 文件下载、来源与验证边界
- 上下文：任务与视图在 URL；草稿按任务键分开保存在当前标签页的 sessionStorage；导航采用原生链接/整页加载，不接入全局最新任务
- 技术详情折叠；固定样例 ID 从未传给正式工具 API

### 4.2 隔离与安全

- 独立 Next/React 预览入口，复用已安装依赖；没有新建 UI 框架或升级依赖
- 独立 layout 不加载正式应用 bootstrap、外部设计脚本、数据库或资源探测
- 本机端口 8098；环境开关与 Host 限制；样例会话 HttpOnly/SameSite cookie；写入检查 Origin
- 文件下载、任务读取和写入均限定本预览会话。另一会话不能读取新建任务或下载其文件
- 样例创建和回复带请求幂等键；版本过期返回 409；失败注入在修改之前返回
- CSP 的连接目标为同源；页面中没有真实模型、HPC、文献或其他服务调用入口
- 启动脚本只清理当前子进程继承的服务变量；隔离路径不指向生产数据库，未复制 `.env`、cookie 或凭据
