# 科研 Agent 工作站前端后端闭环验收记录

日期：2026-06-09

## 本轮修复目标

按照任务规划书“能跑通、能检查、能复现、能汇报”的要求，本轮重点不是继续堆静态 UI，而是把前端关键按钮接入本地后端能力，让页面能够真实触发训练、生成实验文件、写入人工 Gate、导出报告和审计包。

## 已完成的后端对接

- 真实训练入口：`Run House Prices`、`Run Local Experiment` 已接入 `POST /api/tasks/house_prices/run-local-experiment`。
- Code Agent 桥接：`Export Context` 已生成 `workspace/tasks/house_prices/agent_context`，`Import Patch` 已写入 patch 队列。
- 工作流操作：`Dry Run`、`Save`、`Publish` 已写入 `workspace/workflows/house_prices/`。
- 人工审核：`Review Now`、`Approve`、`Reject`、`Approve Submission`、`Reject Submission` 已写入 `workspace/gates/`。
- 报告操作：报告目录切换、`Export Report`、`Submit for Review` 已写入 `workspace/reports/`、`workspace/exports/`、`workspace/gates/`。
- 证据与复现：`Open Folder`、`View full log`、`Edit`、`Add`、`View all` 已写入 `workspace/runtime/` 或 `workspace/evidence/`。
- Shell 操作：工作区选择、通知、用户菜单、Research Mode、搜索框回车已写入 `workspace/runtime/action_log.jsonl`。
- 设计系统样例：Design System 中的按钮样例已接入 `design_sample_action`，避免规范页出现无响应按钮。

## 修复过的交互问题

默认浏览器宽度下，首页三栏工作区曾出现中间 `Artifacts / Open Folder` 被右侧复现记录覆盖的问题，导致按钮看得到但点不到。本轮已将 AppShell 工作区最小宽度从 `1180px` 调整为 `1600px`，避免复杂工作站布局互相压住。

同时，`ArtifactList` 和 `ReproducibilityRecord` 增加了本地 API fallback：即使某个页面复用组件时没有传入父级 action handler，也会直接写入统一 action log，避免出现无响应入口。

## 当前受控限制

- Kaggle 官方下载和 leaderboard 提交仍未接入，因为本机没有配置 Kaggle token；页面中保持为 Reserved / Not Configured，不伪装为已完成。
- GPU 训练仍未接入；当前使用本地 CPU / Python runner 完成可复测闭环。
- `Stop Run` 当前记录停止请求文件，尚不是对正在运行子进程的强制取消器；第一版先满足人工中止意图可审计。
- 新建任务会生成 scaffold 文件，但尚未动态追加到左侧任务队列；后续可接任务列表刷新 API。
