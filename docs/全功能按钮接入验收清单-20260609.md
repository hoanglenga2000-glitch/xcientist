# 科研 Agent 工作站全功能按钮接入验收清单

日期：2026-06-09

## 本轮收口目标

把第一阶段高保真 UI 从“可展示”推进为“可操作、可审计、可复测”的本地系统。重点是所有看起来可点击的功能按钮必须进入真实系统链路：前端事件、Next API、SQLite ActionLog、JSON artifact 或真实实验运行。

## 已完成接入

| 区域 | 控件/行为 | 接入结果 |
| --- | --- | --- |
| 侧边栏 | 页面导航 | `navigate_page` 写入 ActionLog 和 `workspace/ui_state` |
| 顶部栏 | 工作区、通知、用户、搜索回车 | `workspace_select`、`notification_open`、`profile_open`、`search_command` |
| Mission Ledger | 新建任务、选择任务 | 新建任务会创建 DB Task 和 `workspace/tasks/*/task_profile.json`；选择任务写审计 |
| Research Tasks | 阶段选择、全屏、日志查看 | `stage_select`、`open_fullscreen`、`view_full_log` |
| Workflow Graph | 节点库、画布节点、Dry Run/Save/Publish | 选择写 `ui_state`；Dry Run/Save/Publish 更新 Workflow 表和 workflow artifact |
| Code Runner | 运行实验、停止、文件树、编辑器标签、终端标签 | 实验调用 Python orchestrator；停止支持取消；选择类行为写 `ui_state` |
| Code Agent Bridge | Export Context、Import Patch | 生成本地 agent context / patch artifact，并写 ActionLog |
| Agent Runtime | Agent 卡片选择、人工审批 | Agent 选择写 `ui_state`；审批/拒绝创建 Gate 记录 |
| Experiments | 实验谱系选择 | 优先读取 DB runs/evidence；选择写 `experiment_select` |
| Report Studio | 报告章节、导出、提交审核 | 章节写 Report.selectedSection；导出/提交创建 report/gate artifact |
| Integrity Gates | Gate 行打开、提交审批、导出审计包 | Gate 行写 `gate_check_open`；审批创建 Gate；导出 audit manifest |
| Design System | 样式示例按钮 | 写 `design_sample_action`，避免样例按钮成为死控件 |

## 架构修复

- 所有 API route 已显式设置 `dynamic = "force-dynamic"`，避免 Next.js 在生产构建中把数据库 summary 静态化。
- `/api/workstation-summary` 现在能实时反映 ActionLog、runs、gates、evidence、reports、workflows。
- UI 状态类动作统一归档到 `workspace/ui_state/*.json`。
- 保留真实科研任务边界：Kaggle token/GPU 未配置，不伪装为已接入。
