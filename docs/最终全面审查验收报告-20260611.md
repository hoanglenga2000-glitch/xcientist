
## 安全边界

- API Key、SSH 私钥、Kaggle token 不写入 SQLite。
- 推荐使用环境变量、`*_FILE` 或 `WORKSTATION_SECRET_DIR`。
- Claude Code 只能生成 transcript、patch、manifest 和草稿；应用代码必须经过人工 Gate。
- GPU v1 仅允许 SSH 白名单训练模板，不开放任意 shell。
- Kaggle 官方提交需要人工 Gate。

## 仍需资源后完成的真实外部闭环

当你提供资源后，还需要完成：

1. Claude 真实 smoke test：生成 transcript、patch、manifest，并确认人工 Gate 阻断/批准路径。
2. GPU 真实 SSH smoke test：测试连接、校验远程目录、执行白名单训练模板、下载 artifacts。
3. Kaggle token 接入：受控下载/提交，不自动宣称 leaderboard 成绩。
4. 生产部署 profile：按实际服务器环境决定 SQLite 单机版或 PostgreSQL。
