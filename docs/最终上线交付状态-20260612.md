## 安全边界

- API Key、SSH 私钥、Kaggle token 不写入 SQLite。
- 密钥读取方式支持环境变量、`*_FILE` 和 `WORKSTATION_SECRET_DIR`。
- Claude 生成的代码必须经过代码质量 Gate 和人工 Gate。
- GPU 只允许白名单训练模板，不开放任意浏览器终端。
- 未配置资源必须显示 `Not Configured`、`Pending` 或清晰的凭据阻断状态。
