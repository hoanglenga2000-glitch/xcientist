# 高级工具 M1 交互预览

仅本机样例，用于确认“我的任务 → 对话 → 进度 → 文件与结果”的方向。不是正式应用，也不是真实模型或 GPU 验收。

## 启动

在仓库根目录的独立 PowerShell 7 窗口运行：

```powershell
. ./.venv/Scripts/Activate.ps1
python --version
./scripts/start_advanced_tools_preview.ps1
```

打开 <http://127.0.0.1:8098/>。服务只监听回环地址；默认未启用环境开关时页面与接口关闭。启动脚本仅在当前子进程中清除继承的服务变量，不修改用户凭据或配置。

若 8098 已占用，请先核验进程，不要直接结束其他服务。结束本预览可在启动窗口按 Ctrl+C。

## 试用

1. 打开“了解小样本图像分类的方法”，在进度里找到需要补充什么。
2. 回到对话输入内容，点击“查看样例回复”；这是固定样例，不是模型分析。
3. 打开“文件与结果”，预览并下载需求记录。
4. 新任务仅保存预览草稿，不启动执行。任务名称暂取需求前 42 字。
5. 页尾“预览测试”可模拟失败；切回正常后重试。模拟权限提示与真实生产 RBAC 验收不同。

任务数据保存在本预览服务内存中；浏览器刷新不清空，服务重启/开发热更新会重置。输入草稿仅在当前浏览器标签页会话内保存。不要输入密钥或敏感资料；这不是生产级持久化实现。

## 验证

保持预览运行，在前端目录执行：

```powershell
& 'D:/下载/node.exe' preview/advanced-tools/verify.mjs
```

输出在仓库 `artifacts/advanced-tools-usability-20261008/`。脚本核对既有发布源 receipt，比较受影响入口，记录本次新文件白名单，运行隔离 API/交付物/组件测试、两套类型检查及既有状态回归测试。不启动模型、训练或发布。

响应式布局入口：`/viewport?size=mobile`、`desktop`、`wide`。固定 CSS 视口分别为 390×844、1366×768、1920×1080；不等于物理手机/触摸测试。
